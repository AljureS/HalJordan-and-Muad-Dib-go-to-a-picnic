# HalJordan & Muad'Dib

Dos skills para auditar repositorios con Codex (HalJordan) y Claude Code (Muad'Dib). Generan reportes en Markdown con hallazgos priorizados, referencias al código y recomendaciones, sin modificar el código del proyecto.

## Skills

- [Engineering audit Codex–Claude](engineering-audit-codex-claude/SKILL.md): auditoría general de arquitectura, calidad, seguridad y pruebas.
- [Engineering audit HalJordan–Muad'Dib v3](<Engineering audit haljordan muaddib-v3/skills/engineering-audit-haljordan-muaddib/SKILL.md>): auditoría con validación de citas y roles de colaboración definidos: Claude Code coordina; Codex ejecuta y revisa.

Cada skill incluye su `SKILL.md`, una plantilla de reporte en `references/` y utilidades en `scripts/`. Consulta el `SKILL.md` correspondiente para ver el flujo de uso. Los ZIP originales también están incluidos.
